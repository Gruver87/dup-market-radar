Как читать / ручная торговля

  • Score — насколько монета выделяется. Не гарантия прибыли.
  • Смотреть лонг (откат) — рост уже был; ждать откат, не гнаться за пиком.
  • Смотреть отскок — после дампа; агрессивно и рискованно.
  • Купить / Продать — ручной режим. Превью → подтверждение. Работает и при Автоисполнение OFF, и при ON.
  • Автоисполнение: ON/OFF — opt-in. Если ON + keys + dry_run=false, Radar сам шлёт market buy/sell по сигналам спот/мемы/листинги без диалога. Фьючерсы никогда. По умолчанию OFF. Кнопка СТОП — kill-switch.
  • Авто-покупка: setup «лонг/откат» или новый листинг, score ≥ порога, без риск-флагов. Авто-продажа: fade-watch или стоп-лосс % от входа (см. config). Лимиты: размер ордера, max позиций, дневной notional/число сделок, cooldown.
  • Нужен .env с ключами KuCoin. auto_trade.dry_run: true = лог без ордеров (Автоисполнение не «armed»).
  • Telegram — алерты + /time /fx /lang. Токен и chat id в .env.
  • PWA / Android — установи дашборд как приложение (Chrome → «На экран»). Это пульт к радару на хосте, не сервер в телефоне.
  • Сделки — журнал реальных buy/sell и открытые позиции, не список «что купит завтра».
