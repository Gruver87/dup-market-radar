Как читать / ручная торговля

  • Score — насколько монета выделяется. Не гарантия прибыли.
  • Смотреть лонг (откат) — рост уже был; ждать откат, не гнаться за пиком.
  • Смотреть отскок — после дампа; агрессивно и рискованно.
  • Купить / Продать — ручной режим. Превью → подтверждение. Работает и при Авто OFF, и при Авто ON.
  • Авто: ON/OFF — если ON, Radar сам шлёт market buy/sell по сигналам спот/мемы/листинги. Фьючерсы никогда. По умолчанию OFF.
  • Авто-покупка: setup «лонг/откат» или новый листинг, score ≥ порога, без риск-флагов. Авто-продажа: fade-watch или стоп-лосс % от входа (см. config).
  • Нужен .env с ключами KuCoin. Можно включить auto_trade.dry_run: true для лога без ордеров.
  • Telegram — алерты + /time /fx /lang. Токен и chat id в .env.
