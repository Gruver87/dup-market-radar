# С чего начать (обычным языком)

Это инструкция **для человека**, который впервые открыл репозиторий.  
Технические детали: [`TRADE.md`](TRADE.md), [`LIVE_MONEY.md`](LIVE_MONEY.md), [`OPS.md`](OPS.md).

**Не финансовый совет.** Деньги на бирже — ваш риск.

---

## Что это вообще такое?

**DUP Market Radar** — программа на вашем компьютере, которая:

1. Смотрит рынок (спот, мемы, листинги, фьючерсы только как **наблюдение**).
2. Показывает таблицу и сигналы в браузере.
3. *По желанию* может отправлять **спот**-ордера на KuCoin.

По умолчанию она **ничего не покупает сама**. Автопокупка включается отдельно и осознанно.

---

## Режим A — только смотреть (безопасно)

Нужно: Windows, Python 3.11+, интернет.

```powershell
cd dup-market-radar
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
.\scripts\run_radar.ps1
```

Откройте в браузере: [http://127.0.0.1:8787/](http://127.0.0.1:8787/)

- Смотрите вкладки Watchlist / Markets / Ops.
- Кнопки «Купить / Продать» без ключей KuCoin **не сработают** на реальные деньги — это нормально.
- «Авто: ON» в интерфейсе ≠ автопокупка. Автопокупка = **«Автоисполнение»**.

---

## Режим B — ручная покупка на KuCoin

1. Создайте API-ключ KuCoin с правом **Spot Trade** (не давайте Withdraw, если не нужно).
2. Пропишите ключи в `.env` (файл **никогда** не коммитьте в git):
   - `KUCOIN_API_KEY`
   - `KUCOIN_API_SECRET`
   - `KUCOIN_API_PASSPHRASE`
3. Перезапустите Radar.
4. В дашборде: **Превью → подтверждение**. Два раза спросите себя: «это реальное исполнение?».

---

## Режим C — автопокупка / автопродажа (opt-in)

Только если вы понимаете риски. Чеклист: [`LIVE_MONEY.md`](LIVE_MONEY.md).

Кратко:

1. `.\scripts\go_live_money.ps1` должен показать **PASS** (ключи + native + ops-ready).
2. Запуск с профилем живых денег:

```powershell
$env:RADAR_PROFILE = "live-money"
$env:RADAR_REQUIRE_API_KEY = "1"
.\scripts\run_radar.ps1
```

3. В дашборде включите **Автоисполнение: ON** и дождитесь статуса **ARMED**.
4. Аварийная кнопка **СТОП** сразу выключает авторежим.

### Как считаются суммы (с версии 0.2.110)

Не «всегда 25 USDT», а **равные рукава** от свободного USDT:

- Свободный USDT делится на 3 сектора: `spot_alts` / `memes` / `listings`.
- Покупка в секторе тратит кассу этого рукава.
- Продажа возвращает деньги **в тот же рукава** (прибыль/убыток остаются «своими»).
- Фьючерсы в авто **никогда**.

Подробности: [`TRADE.md`](TRADE.md).

## Частые вопросы

**Почему ничего не покупает?**  
Автоисполнение выключено, или нет ARMED, или нет сигнала с нужным score, или рукав пуст / уже есть позиция в этом секторе.

**Это заработок?**  
Нет гарантий. Это инструмент + эвристики. Убытки возможны.

**Что такое CI / verify / soak?**  
- CI зелёный = тесты в GitHub прошли.  
- `verify` Quick/Full = проверки на машине, **не** 48-часовой soak.  
- 48h soak — отдельный долгий прогон с пакетом улик; без пакета нельзя писать «PASS».

**Где телефон?**  
PWA: [`PWA.md`](PWA.md) — ярлык на телефон, сервер всё равно на ПК.
